# Confluence Structure Template

Template for organizing Initiative documentation in Confluence.

## Directory Structure (Leaf Bundle Pattern)

```
docs/confluence/{instance}/{space}/{initiative-name}/
├── index.md                        # Initiative Overview
├── strategic-context/
│   └── index.md                    # Business goals
├── technical-architecture/
│   └── index.md                    # System design
├── decisions/
│   └── index.md                    # Decision logs
├── research-and-findings/
│   └── index.md                    # User research
├── assumptions/
│   └── index.md                    # Assumptions
└── implementation-guidance/
    └── index.md                    # Technical guides
```

## Page Template

```markdown
---
confluence_page_id: null
confluence_space_key: "SPACEKEY"
confluence_title: "Page Title"
confluence_url: null
parent_page_id: "parent_id"
---

# {Page Title}

{Purpose of this page}

## BMAD Documentation
{Primary content from BMAD docs}

{Agent-generated context}

## Related Pages

## Jira Tickets

```

## Content Organization

### Initiative Overview
- Summary, strategic goals, epic links, quick navigation

### Strategic Context
- BMAD PRD content, product vision, success criteria

### Technical Architecture
- BMAD Architecture docs, system design, constraints

### Decisions
- Consolidated decision logs, chronological order

### Research & Findings
- User research, clarifications, feedback

### Assumptions
- Grouped by confidence level, validation status
